# UI 模块设计

更新时间：2026-07-06

## 2026-07-06 首页头部 / 反馈弹窗 / 成员删除 UI

- 首页右上角头像不再显示红点（`showStatusDot` 属性已移除）。
- 首页标题改为滚动轮播：`RollingTitle` 组件每 8 秒淡入淡出切换，传入 `titlePool` 启用。
- 「功能建议」和「问题反馈」合并为「反馈与建议」入口；点击后弹出底部 `AppModalSheet`（`FeedbackSheet`），弹窗内可切换类型，不切换面板模式。
- 成员详情页新增 danger 样式删除按钮，带二次确认和所有者保护。

## 2026-07-05 紧凑首页与账号面板 UI 规则

- 底部主导航只显示首页、计划、记录；账号、设置、同步、权益和法务入口从首页右上头像面板进入。
- 首页使用浅灰背景、白色圆角卡片、轻阴影、珊瑚红主按钮、深色标题和灰蓝副文案。
- 首页顶部右侧使用 36-42dp 用户头像，不再使用通知铃铛、普通设置按钮或按小时问候。
- 首页头部标题必须来自短训练文案池，例如“今天也别空过”“这一组算数”；不得展示今日训练标题、训练重点或按小时问候。
- 首页副标题只承载日期、当前小组人数或短同步状态，避免挤压右上头像。
- 当前计划进度只放在压缩计划卡内，不再重复展示独立当前周数模块。
- 今日训练 Hero 使用本地训练图片和深色遮罩，尺寸控制为首屏可容纳更多内容；只展示训练重点和指标，不放开始训练按钮。
- 当前小组与开始训练合并为横向卡片；复杂成员管理、邀请成员或切换小组入口不出现在首页卡片中。
- 今日重点列表使用紧凑行高，首屏至少露出 1-2 个动作条目。
- 账号面板从右上头像附近展开，不居中、不贴底、没有底部关闭叉号，主菜单保持紧凑分组列表。
- 账号面板顶部头像 + 昵称摘要就是个人信息入口；主菜单不单独展示“个人资料”行。
- 个人信息编辑在面板内子状态完成，保存按钮只在右上角按变更状态出现。
- 编辑个人信息顶部只放头像、昵称、手机号和练刻 ID；头像点击直接打开操作，不在头像旁显示说明文案或长同步状态。
- 性别字段默认只显示当前值或“选择性别”，点击后展开选择男 / 女 / 其他 / 不展示；选择后收起。
- 云同步、数据备份、训练偏好、会员 / 激活码、功能建议、问题反馈必须直接显示内容和可操作项，不再放“查看详情 / 打开设置”二次按钮。
- “设置与反馈”不作为账号面板入口；功能建议和问题反馈上移到反馈与法务分组。
- “切换小组”和“管理小组与成员”合并为一个“训练小组”入口，在面板子状态内处理切换和管理跳转。

## 2026-06-30 训练选择与低频入口规则

- 今日训练页的动作取舍入口命名为“动作筛选”，不得继续使用旧状态类命名作为用户主文案；它影响本次 session 的计划动作快照。
- 计划页主界面不铺开系统方案长列表；系统方案统一进入“计划库”弹层。
- 历史详情默认只读，编辑态和删除动作由更多菜单触发，避免普通查看记录时误操作。
- 普通二级页只保留系统返回，不叠加重复标题和大块顶部留白。
- 折线趋势图必须使用真实坐标、单位和绘图区 padding；空数据不画假图。
- 训练执行页以重量、次数、完成本组为核心；RPE、备注、替换动作等低频能力不得抢主操作。
- 身体数据页默认快速记录体重，围度和目标设置折叠承载。

## 2026-06-29 记录 / 计划 / 同步入口 UI 规则

- 记录页支持个人 / 小组分段视角；小组视角必须展示本机 SQLite 推导的总览、成员贡献、折线趋势、最近小组训练和洞察，不得用开发中占位或假头像假数据。
- 记录页、训练分析页、计划执行趋势统一使用折线趋势图；不再使用柱状图、胶囊柱或椭圆柱表达训练量与趋势。
- 计划页低频工具收进“计划操作”底部弹层；页面中部不展示大块“计划工具”网格。
- 普通用户界面不展示“云同步 / 数据同步 / 待同步 / 同步状态 / 从云端恢复”等入口或模块；底层预留代码不作为用户主流程展示。
- 在线邀请、二维码加入、在线同练等未实现能力不作为首页或搭子页主入口展示；统一使用“该功能正在开发中，后续版本开放。”说明。

## 页面布局原则

- 首页是今日训练任务中心：短训练文案、当前计划、今日训练 Hero、当前小组开始训练、今日重点和必要空状态。
- 计划页是计划管理中心：当前计划、阶段进度、本周安排、我的计划、系统方案、创建、复制、导入、导出。
- 记录页是数据分析中心：预估 1RM、PR、完成率、训练量、趋势、近期训练和分析建议。
- 我的页是账号与训练入口：训练档案、小组成员、偏好设置、账号设置和关于练刻；退出登录放在账号设置。
- 训练执行页使用沉浸式全屏，不显示底部 Tab。
