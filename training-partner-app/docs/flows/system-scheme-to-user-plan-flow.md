# 系统方案复制为用户计划流程

更新时间：2026-07-15

## 1. 目标

系统方案是只读模板，不能直接执行训练。用户必须点击“使用此方案”后，App 才复制生成一份本地用户计划。

## 2. 主流程

```text
打开计划页或探索页
-> `/plan/library` 筛选/搜索方案元数据
-> `/plan/scheme/[schemeId]` 批量读取完整模板详情
-> 查找 `originSchemeId` 相同的用户副本
-> 已有副本默认复用；新副本检查数量权限并复制
-> 明确“再复制一份”后才允许重复复制
-> `activateTrainingPlanForGroup`
-> `ensureActivePlanCycle`
-> 返回计划页，或“复制并编辑”进入用户副本编辑页
```

## 3. 数据规则

- 新计划 `source = system_copy`。
- 新计划记录 `originSchemeId`。
- phases、days、plan exercises 都生成新的本地 ID。
- 系统方案不会进入“我的计划”。
- 训练记录不会绑定系统方案。

## 4. 异常流程

- 系统方案开发中：显示“开发中”。
- 系统模板不存在：显示中文错误提示。
- SQLite 写入失败：复制失败并提示，不创建半成品计划。

## 5. 验收点

- “我的计划”只显示用户计划。
- 点击完整可用系统方案后能生成用户计划。
- 复制或复用成功后立即成为当前计划并具有活动周期。
- 今日训练读取当前用户计划。
