# 创建计划流程

更新时间：2026-07-10

## 1. 目标

用户可以从空白创建自己的训练计划。第一版先保留入口，深层编辑器后续 Sprint 接入。

## 2. 目标字段

- 计划名称。
- 训练目标。
- 每周训练频率。
- 周期周数。
- 训练日。
- 动作。
- 组数。
- 次数。
- 百分比。
- 完成状态。
- A/B/C 优先级。
- 休息时间。

## 3. 计划来源

空白创建的用户计划建议使用：

```text
source = blank_created
originSchemeId = null
```

## 4. 当前实现

计划页已提供“创建计划”入口和多训练日编辑器。页面内容为组件草稿，进入页面不会提前写入 `plan_templates`；用户点击保存且每个训练日都有动作后，才在 SQLite 事务中写入完整计划。新建成功后立即设为当前小组计划。

## 5. 后续实现要求

- 创建后的计划必须进入“我的计划”。
- 创建后的计划可以设为当前计划。
- 创建计划不能修改系统方案。
- 创建计划不能覆盖已有计划。
