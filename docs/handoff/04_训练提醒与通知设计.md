# 04 训练提醒与通知设计

## 一、功能判断

训练提醒应该进入架构。  
第一版优先做本地通知，服务端推送先预留。

## 二、提醒类型

建议支持：

```text
fixed_time：固定时间提醒
before_workout：训练前提醒
today_plan：当天计划提醒
missed_workout：未训练提醒
cycle_review：周期总结提醒
```

## 三、第一版本地通知

第一版可以做：

```text
1. 用户设置每周训练时间。
2. 提前 30 分钟提醒。
3. 提前 10 分钟提醒。
4. 当天提醒今日计划。
5. 通知点击后打开今日页或训练页。
```

通知示例：

```text
还有 30 分钟开始训练
今日计划：胸 + 三头
准备好训练装备，按计划开始。
```

## 六、第一版要做

```text
1. 本地通知权限申请。
2. 训练前 30 分钟提醒。
3. 训练前 10 分钟提醒。
4. 按计划日生成提醒。
5. 设置页提供提醒开关。
```
